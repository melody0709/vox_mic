# 🎙️ 麦克风音频参数精调指南 (Audio Settings Guide)

**简体中文** | [English](../../Audio_Settings_Guide.md)

这份指南将详细解释音频设置面板中每个参数的具体作用，帮助你根据不同的使用场景，调出最清晰、最自然的人声。

---

## ⚙️ 第一部分：基础输入设置 (Basic Settings)

这一部分主要控制麦克风的原始输入以及调用系统（如 Android 底层）的硬件级处理。

### 1. Gain (输入增益)
*   **作用**：控制麦克风原始声音放大的倍数。
*   **怎么调**：
    *   **1.00x (推荐)**：保持麦克风原始音量。如果你的声音本来就足够大，保持 1.0x 可以最大程度避免爆音（声音失真）。
    *   **> 1.00x**：如果你说话声音很小，或者麦克风离嘴巴很远，可以适当调大（如 1.2x - 1.5x）。但注意，调大增益也会同时放大背景底噪。

### 2. NoiseSuppressor (系统硬件降噪)
*   **作用**：调用设备（如手机底层系统）自带的降噪算法。
*   **怎么调**：**建议【关闭】（取消勾选）**。
    *   **原因**：如果你打算使用下方的 `Noise Reduction` (DSP 高级降噪)，就千万不要开这个。同时开启两者会导致“双重降噪”，过度裁剪音频信号，让人声听起来发闷、像机器音。把降噪工作交给下方更智能的 DSP 模块即可。

### 3. AcousticEchoCanceler (回声消除 - AEC)
*   **作用**：消除扬声器播放的声音被麦克风重新录进去所产生的回音。
*   **怎么调**：
    *   **如果你戴耳机**：可以**关闭**，因为耳机不会产生回声，关闭可以减少一点点音质损耗。
    *   **如果你用外放扬声器**：必须**开启**，否则对方会听到他们自己的回音。

### 4. AutomaticGainControl (系统自动增益 - AGC)
*   **作用**：系统自带的“自动音量调节手”，声音小了它自动拉大，声音大了它自动压小。
*   **怎么调**：**建议【关闭】（取消勾选）**。
    *   **原因**：如果你开启了下方的 `Compressor Enable` (压缩器)，两者会相互打架（冲突），导致声音忽大忽小，很不自然。建议关闭系统 AGC，让 DSP 压缩器来接管动态控制。

## 🎛️ 第二部分：DSP 高级音频处理 (DSP Audio Enhance)

这一部分是核心，使用软件算法对音频进行精雕细琢，决定了最终声音的“质感”和“清晰度”。

### 1. EQ Enable (均衡器开启)
*   **作用**：总开关，开启后下方的 `Presence` 和 `Bass Cut` 才会生效。强烈建议**开启**。

#### 1.1 Presence (临场感 / 高频补偿)
*   **作用**：提升中高频段（通常在 2kHz - 6kHz 左右）。这决定了人声的**“清晰度”、“穿透力”和“唇齿音”**。
*   **怎么调**：
    *   像调节电视机的“锐度”一样。开启降噪后，声音容易发闷，适当提高这个值（如 **+3.0 dB 到 +5.0 dB**）能把丢失的清晰度强行补回来。
    *   *注意*：如果调得过高（比如 +8dB 以上），声音会变得刺耳，齿音（嘶嘶声）会很严重。

#### 1.2 Bass Cut (低频切除 / 高通滤波)
*   **作用**：削弱低频段（通常在 100Hz 以下）。
*   **怎么调**：
    *   **-3.0 dB 到 -6.0 dB (推荐)**：能有效过滤掉麦克风的喷麦声（噗噗声）、桌子的震动声、以及远处的环境轰隆声，让人声显得更干净。

### 2. Compressor Enable (压缩器)
*   **作用**：音频动态范围的“熨斗”。它把太大的声音压下去，把太小的声音提上来，让整体音量保持平稳。
*   **怎么调**：**建议【开启】**。
    *   这让你在激动大喊时不会爆音，在小声嘟囔时别人也能听清。它比系统的 AGC 更加平滑、专业。

### 3. Noise Reduction (DSP 软件降噪)
*   **作用**：使用神经网络算法消除风扇声、键盘声等背景噪音。
*   **后端选择**：
    *   **RNNoise (built-in)**：默认后端，内置在 VoxMic 中，无外部 DLL/模型依赖；`NR Strength` 滑块只对它生效。
    *   **DPDFNet (48 kHz model)**：可选的流式 ONNX 后端，适用于当前 48 kHz / 480-sample 音频链路。它需要 DPDFNet 构建载荷中的 DLL 与 `models/dpdfnet2_48khz_hr.onnx`。
    *   如果 DPDFNet 文件缺失、版本不匹配或初始化失败，程序会明确记录原因并自动回退 RNNoise；不会导致 VoxMic 启动失败。
*   **怎么调**：根据环境决定。
    *   **嘈杂环境（推荐开启）**：降噪效果极好，但代价是会稍微吃掉一点高频（导致声音变闷）。**必须配合调高 `Presence` 来使用**。
*   **安静房间（推荐关闭）**：如果你的房间本来就很安静，关闭它可以获得最完美、最保真的广播级人声音质。

选择 DPDFNet 后，`NR Strength` 会被禁用，因为当前在线 DPDFNet 模型没有可直接映射的强度参数；切换回 RNNoise 后，原来的 RNNoise 强度值会恢复。DPDFNet 的模型、CPU provider 和推理线程数由发布载荷固定，不建议在 Settings 中暴露。

如果 DPDFNet worker 在流切换后的短暂预热期没有立即产出，最多会保留 4 个 10ms 静音块以维持时间对齐；稳态连续 3 个 block 无输出时会自动降级到 RNNoise。设置页会显示 degraded 状态，点击 OK 或下一次流 reset（例如重连、重新激活或重新选择后端）会再次尝试仍可用的 DPDFNet worker；session 硬失败则需要重新 prepare。

## 🏆 总结：最佳场景推荐配置

### 场景 A：日常使用 / 有一点底噪的房间（你目前的配置 - 推荐）
*   **系统处理**：全部关闭（只留 AEC 视情况开启）。Gain 设为 1.3x。
*   **DSP 降噪**：开启 (`Noise Reduction` ✅)
*   **EQ 补偿**：开启。`Presence` +4.0dB，`Bass Cut` -3.0dB。
*   **动态控制**：开启压缩器 (`Compressor` ✅)。
*   *效果*：没有环境噪音，人声清晰稳定，适合 90% 的场景。

### 场景 B：绝对安静的房间 / 追求极致原音
*   **系统处理**：全部关闭。
*   **DSP 降噪**：**关闭** (`Noise Reduction` ❌)。
*   **EQ 补偿**：开启。`Presence` +1.0dB (稍微提亮即可)，`Bass Cut` -3.0dB (防低频隆隆声)。
*   **动态控制**：开启压缩器 (`Compressor` ✅)。
*   *效果*：最大程度还原真实声音细节，音质最好，但对环境安静度要求高。
